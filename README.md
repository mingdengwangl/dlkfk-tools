## 常见问题

<details>
<summary><b>海外能用吗？国外能用抖音引流工具吗？</b></summary>

可以。工具支持独立 IP 与代理配置，北美、加拿大、澳洲、新加坡、马来西亚、日本、英国均有用户在正常使用。
海外华人做抖音、小红书运营的场景已验证。详见 [使用文档](https://www.dlkfk.cn/news)。
</details>

<details>
<summary><b>批量私信会封号吗？账号被封怎么办？</b></summary>

工具内置频率控制、话术轮换与指纹隔离。按推荐参数使用、配合正常养号流程，风险可控。
具体设置见 [抖音矩阵账号防封设置详解](https://www.dlkfk.cn/article/39) 与
[抖音批量私信被封号的真正原因](https://www.dlkfk.cn/article/41)。
</details>

<details>
<summary><b>养号要多久？新号能直接用吗？</b></summary>

建议新号先养 3-7 天（正常浏览、点赞、关注），权重上来后再开始批量操作。
工具有自动养号模块可以托管这个过程，见 [抖音批量矩阵养号全流程](https://www.dlkfk.cn/article/4)。
</details>

<details>
<summary><b>采集工具好用吗？能采到什么数据？</b></summary>

评论区可采：评论内容、用户昵称、UID、评论时间、楼中楼回复。
直播间可采：实时弹幕、进场用户、互动记录。
支持关键词过滤，只保留有购买意向的客户。见 [抖音评论区采集实战](https://www.dlkfk.cn/article/1)。
</details>

<details>
<summary><b>需要什么配置？</b></summary>

Windows 系统，4GB 内存起步。多账号矩阵建议 8GB 以上。
支持独立 IP、指纹浏览器环境隔离。
</details>
